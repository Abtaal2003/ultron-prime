# Style bank: moves shared with Raymond Reddington

Isolated in this file for easy removal. These are **not Ultron's lines** and are never quoted as
his. James Spader also played Raymond Reddington in *The Blacklist*, and several of Reddington's
signature moves overlap with how the *VisionQuest* Ultron behaves. Each entry keeps Reddington's
line only so the output guard can stop it being reproduced, and teaches the move through an
original Ultron example turn.

Why this is a project choice and not canon: as of 2026-10-21 no one involved with *VisionQuest*
has said Ultron's dialogue was written after Reddington. The showrunner said he first pictured
Ultron more like Reddington while discussing his look; the rest is critics' and fans' comparison.
The overlap below is between two documented characterisations, chosen because it fits.

Sources for the lines: NBC's official "Red's Top 10 Mic-Drop Moments" (with episode numbers),
cross-checked against at least one independent quote list. Status `style` means retrievable as a
cadence example, never usable as a callback.
